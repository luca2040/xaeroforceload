## xaeroforceload
Minecraft Neoforge 1.21.1 mod to add the option
to manage always loaded chunks (same as `/forceload`)
via the Xaero's World Map.

This mod is optional client-side and required server-side.
Note that just the players with the mod installed on the client can use it.

Also, compatibility is not verified with every xaero world/minimap version.
The only verified working setup is with `26.4.2 minimap` and `1.44.2 worldmap` on `21.1.248 neoforge`.
